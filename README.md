# Regula MT TC — app do iPhone

App do médico regulador para ver a fila de tomografias do RegulaMT (UPAs e Policlínica de Cuiabá)
e receber alertas. Os dados vêm do app do notebook, pelo Supabase, e só o usuário logado vê.
Este repositório contém apenas o site (sem dados de pacientes nem senhas).

Endereço: https://luizyabumoto.github.io/regulamt-tc/
